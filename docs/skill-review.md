# 六项能力与外接边界审查

审查日期：2026-10-10。对象：当前 privacy-review Skill、CLI、规则与 MCP 实现。只读审查实现，未修改产品代码、安装客户端、读取真实凭据或扫描真实 Agent 运行目录。

本文件保留增补前审查结论作为历史基线。后续 v0.3 已按用户要求增补能力并修复目录/参数问题，当前实现与实际验证见 docs/acceptance.md、docs/architecture.md；不能把下面的“未实现/未修复”当成增补后的状态。

## 结论

当前实现满足按需外接、只读给建议的基本形态，但不能宣称六项防泄漏能力已齐备。Skill 是调用与解释层，规则代码是约束本工具行为的执行层；未建立宿主全局外发检查或不可绕过的权限边界。

| 用户目标 | 当前证据与缺口 |
| --- | --- |
| 无侵入外载 | CLI / stdio MCP 可外接，不修改目标项目；独立复制 Skill 仍需引擎与 gitleaks，并非自包含包。实际客户端安装体验未验收。 |
| 固定内容强约束 | 只读 API、结构化脱敏结果、不完整标志已有代码约束。宿主必须调用、不得读取其他文件、不得自动执行建议仍是文字要求。根目录判断和 CLI 错误回显存在漏洞，见下文。 |

## 优先问题

### P1：保护只看相对路径，遗漏检查根目录

`advisory.protected_path` 只检查传入的相对名称；`review_files` 没有验证根目录是否为 Agent 运行目录或位于其内。如果用户指定 `.codex` 为根目录，`memory.md` 不带隐藏目录段，会被打开。根目录内符号链接指向受保护目录时，目标仍在允许根目录内也可能绕过这类名称判断。

合成复现：在隔离系统临时目录创建 `.codex/memory.md`，记录 `Path.read_bytes` 调用，替换后续扫描器以免读取更多内容。结果 `runtime_root_content_opened=true`。没有使用真实 Agent 目录。

建议：在读取前同时验证根目录、完整解析路径及祖先目录；各入口共享受保护来源判断。受保护来源仅返回静态路径风险和未检查状态。

### P1：CLI 参数错误回显输入

`cli.main` 直接调用 argparse 默认错误处理。未知参数等解析失败会在 stderr 回显参数值，绕过正常 JSON 的脱敏输出。

合成复现：未知参数附带运行时测试标记，子进程输出中检测到该标记，退出码 2。只记录布尔结果，不记录原始参数。

建议：解析失败转换为固定错误与 `review_complete=false`；Skill 启动器和所有产品入口采用一致错误 schema，不回显异常或输入。

### P2：需求与 Skill 的能力描述缺少可验收边界

没有区分“识别敏感资料来源”“扫描用户指定外发材料”“约束宿主读取与外发”。目前只实现第二类的一部分。Skill 应明确六项能力状态、未检查项和调用时点，并避免将按需检查表述为自动防泄漏。

### P2：push 检查示例的范围容易产生误解

`origin/main` 不能通用代表此次推送目的 ref。历史检查不读取真实推送计划，也不会绑定结果与后续 push；多 ref、标签和审查后新增提交不能由一次固定示例覆盖。应由用户提供明确拟推送 refs/范围，并在报告说明覆盖范围与复查条件。

## 建议的职责分工

保留外接 Skill / MCP → 本机规则引擎 → 脱敏报告 → 用户决定的结构。

- Skill：收集明确检查对象、调用工具、解释证据并交付建议；不直接读取敏感源文件，不执行修改或推送。
- 规则引擎：在读取前识别受保护来源，固定扫描密钥、路径和可规则化的 PII；限定输入和输出，失败统一标为未完成。
- Memory / History：对受保护运行目录只做来源提示；对用户明确提供的合成或导出副本设计来源类型和规则，不为提高覆盖率读取真实认证目录。
- 语义层：后续可选本地分析用户指定的允许材料；只能增加风险或不确定性，不能取消规则命中，不把无命中解释为安全，不将建议转为执行动作。
- push：显式复核拟推送的本机 ref 范围，输出覆盖信息；不安装 hook、不实际推送、不承诺自动阻断。

强约束可保证本工具遵守上述规则；要保证宿主所有读取/外发行为都先经检查，需要宿主提供执行边界，当前按需 Skill / MCP 方案没有这个边界。

## 本次验证

Windows、本项目 `.venv`，Python 3.14。使用全新 GUID pytest basetemp，现有全量测试 **57 passed in 25.33s**。现有回归通过不抵消上述新增复现。

运行时合成内容的规则检查：普通记忆导出、普通聊天导出、Windows 正文路径、POSIX 正文路径均无专用规则命中。该检查仅证明这些给定样本和规则缺口，不是 precision/recall 数据集评测。

未验证：真实客户端接入；真实推送过程；UNC 路径独立复现；语义模型；实际 Memory / History 来源适配；受保护根目录修复；参数错误脱敏修复。
